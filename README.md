# Cadru

Un website builder / CMS minimal, într-un singur fișier HTML. Fără backend, fără build, fără colțuri rotunjite.

## Ce face

- **Pagini** – adaugi, redenumești, reordonezi și ștergi pagini; meniul se generează singur.
- **Blocuri** – hero, titlu, text, imagine, două coloane, listă, citat, buton, linie, spațiu.
- **Editare** – click pe un bloc în canvas, modifici în panoul din dreapta; drag & drop pentru reordonare.
- **Site** – nume, text subsol, font (grotesc / mono / serif), culoare accent.
- **Previzualizare** – vezi site-ul exact cum va arăta, cu navigare între pagini.
- **Export HTML** – un singur fișier `index.html` cu toate paginile, gata de urcat pe orice hosting static.
- **Salvare automată** în browser (localStorage) și undo (Ctrl+Z).

## Cum rulezi

Deschide `index.html` în browser. Atât.

## Stack

HTML + CSS + JavaScript vanilla. Fonturi: Archivo și IBM Plex Mono (Google Fonts).
